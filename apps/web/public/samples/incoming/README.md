# Example photos for demo sites

Demo sites show example rooms and a gallery until the owner adds their own.
Put royalty-free photos here, in these folders (any names, JPG, PNG or WebP,
at least 1600px wide), then run `pnpm --filter web sample-photos`:

| Folder | What | How many |
| --- | --- | --- |
| `mountains/`, `lake/`, `bush/`, `river/`, `city/`, `farm/` | The view and the outside, for that setting | 3–4 each |
| `rooms/` | Bedrooms: made beds, chairs, light | 8–10 |
| `food/` | Breakfast, a table set for dinner | 3–4 |
| `outside/` | Verandas, gardens, a lodge from outside | 3–4 |

Use photos whose licence allows commercial use without credit (Unsplash and
Pexels licences do), and list where each came from in `CREDITS.md` here.
